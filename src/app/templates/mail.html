Mail Server

The stack sends mail through one internal relay. It holds the credentials of your mail server and forwards to it, so no other service needs them. Keycloak uses it for password mails, and the Users page offers “email a link” once it is on.

STARTTLS (port 587) and TLS (port 465) verify the server's certificate. Without encryption (port 25) no login is possible: it would cross the network in the clear.

Your provider may only accept addresses it knows: a verified identity, a mailbox or an alias. The relay sends only from the domain of this address.

Good to know

  • The relay accepts and queues mail. If the mail server is down, messages wait and are retried for a day; the status above shows how many are waiting.
  • The password is never shown. Leave the field empty to keep the stored one, which is only used for the same server, port and login it was stored with.
  • Any container on a network the relay is attached to can send mail from the sender domain without a login.
  • There is one sender domain. Switching the relay off keeps these settings.

Switch the mail relay off?

The relay is stopped and leaves the stack, and Keycloak loses the mail server it set, so password mails and “email a link” stop working. The settings and the password are kept, and so are messages that are still waiting in its queue.
