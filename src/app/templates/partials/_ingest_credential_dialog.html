{# The dialog that stores a credential, shared by the job editor and the Credentials page. What is typed here goes to the manager, which encrypts it into secrets.yaml and never sends it back: a stored value cannot be read, only replaced. The field is wiped as soon as it was sent, and after a successful save the dialog announces the name (`credential-saved`) so the page that opened it can use it. Included once per page, outside anything that is swapped. #}

A password, key or token for a source. It is stored encrypted and is not shown again; you can replace it, not read it.

Capital letters, digits and underscores. Jobs refer to it by this name.
