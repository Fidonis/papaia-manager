Third-party icons bundled with the manager
==========================================

These files are shown on the dashboard next to the default tiles. Each one
depicts a product and only identifies it. The manager is not affiliated with,
endorsed by or sponsored by any of them. Product names and logos are the
property of their respective owners (see TRADEMARK.md in the repository).

The files are unmodified copies of the sources named below. Every .svg file
in this directory needs an entry here, with its file name alone at the start of
a line; tests/test_icon_assets.py checks that.

If you own one of these marks and want its icon changed or removed, open an
issue at https://github.com/Fidonis/papaia-manager/issues.
